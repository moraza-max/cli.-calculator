# CLI Calculator

A simple Python-based Command Line Interface (CLI) Calculator that performs both **basic arithmetic** and **scientific operations** directly from the terminal.

---

## Features
- Basic Operations: Addition, Subtraction, Multiplication, Division  
- Error handling for division by zero  
- Scientific Functions:  
  - sin(x)  
  - cos(x)  
  - tan(x)  
  - log(x)  
  - sqrt(x)  

---

## Installation
Clone the repository and navigate into the folder:
```bash
git clone https://github.com/moraza-max/CLI-Calculator
cd CLI-Calculator

Run the program using Python:

python cli_calculator.py

You will see a menu like this:
--- CLI Calculator ---
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Scientific Functions
6. Exit

Choose an option, enter values, and get results instantly.
